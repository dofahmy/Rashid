# تحليل جان — Patch للباك إند

يفتح تاب جديد على `/gann`.

الطرق:
- Gann Square Low / High / Range
- Master Square of 144
- نسب 1/4، 1/3، 3/8، 1/2، 5/8، 2/3، 3/4، 7/8
- Mikula Square of Nine: 45°..360°
- Mikula 225° cell counts: 9,25,49,81,121...

مصدر البيانات: جدول `market_candles_1d` الموجود بالفعل.

التركيب:
```bash
python install_gann_tab.py
```
ثم commit/push وRedeploy لخدمة Web فقط.

القوة % هي درجة التقاء هندسية، وليست probability تاريخية. Full square و1/2 أعلى، ثم 1/4 و3/4، ثم 1/3 و2/3، ثم 3/8 و5/8 و7/8. Cardinal 90/180/270/360 أقوى من Fixed 45/135/225/315، والتقاء أكثر من طريقة يضيف bonus.

## إضافة التوقعات السابقة
صفحة كل سهم تعرض أيضًا آخر قمتين متوقعتين سابقتين وآخر قاعين متوقعين سابقين على نفس الشارت.
هذه العلامات تُبنى من Pivot تاريخي سابق والبيانات المعروفة عنده؛ لا يتم أخذ القمة/القاع الفعلي من المستقبل لصناعة العلامة.
