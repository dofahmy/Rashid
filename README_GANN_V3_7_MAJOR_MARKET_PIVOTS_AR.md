# Gann V3.7 — Principal EGX Market Pivots

التعديل الأساسي:
- تاريخ كامل تقريبًا من 2019 بدل آخر 900 جلسة فقط.
- Market Score الأدنى = 90.
- الحد الأدنى للحركة بين القاع والقمة المعتمدين = 15%.
- Follow-through إلزامي >= 10% بعد القاع/القمة.
- القاع الرئيسي يحتاج Breadth >= 55%.
- القمة الرئيسية تحتاج Breadth >= 30%.
- دمج القمم/القيعان القريبة زمنيًا.
- فرض سلسلة متعاقبة LOW -> HIGH -> LOW -> HIGH.
- إزالة zigzags الصغيرة حتى لو Score مرتفع.
- توقعات جان المستقبلية في مصر تبدأ فقط من:
  * آخر Major LOW مؤكد
  * آخر Major HIGH مؤكد
- التقييم التاريخي يظل يستخدم سلسلة الـMajor pivots المقبولة كلها.

بعد Deploy شغلي:
```bash
python check_egx_market_pivots.py
```

المتوقع أن يكون عدد الـpivots أقل كثيرًا من النسخة السابقة.
