# Gann V3.4 — Decision View

التعديلات:
- عرض مستويين رئيسيين فقط للقمم ومستويين فقط للقيعان.
- دمج المستويات المتقاربة ثم ترتيبها بقوة الالتقاء الهندسي.
- عدم إغراق الشارت بكل خطوط الطرق.
- التوقعات السابقة أصبح لها تقييم: تحقق / تحقق جزئي / لم يتحقق.
- لكل توقع سابق: السعر المتوقع، التاريخ المتوقع، السعر الفعلي، التاريخ الفعلي، فرق السعر، فرق الجلسات.
- على الشارت: سهم فوق القمة السابقة وسهم تحت القاع السابق.
- ألوان التحقق: أخضر / برتقالي / أحمر.
- المستويات القادمة فقط تظهر كخطوط أفقية رئيسية.
- كل المستويات، تفاصيل الطرق، والنوافذ الزمنية موجودة لكن داخل أقسام قابلة للفتح.
- التوقع التاريخي لا يُعتبر متاحًا قبل تأكيد الـpivot بعد 7 جلسات، لتقليل look-ahead.

قاعدة التقييم الافتراضية:
- تحقق: فرق السعر <= 3% وفرق الزمن <= 3 جلسات.
- تحقق جزئي: فرق السعر <= 3% مع فرق زمن <= 7 جلسات، أو فرق السعر <= 6% مع فرق زمن <= 3 جلسات.
- خلاف ذلك: لم يتحقق.
