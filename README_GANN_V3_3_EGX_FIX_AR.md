# Gann V3.3 — Egypt data persistence fix

المشكلة التي تم إصلاحها:
فحص EGX كان يجلب بيانات Yahoo ويحلل إشارات مصر، لكنه لم يكن يحفظ شموع مصر في
`market_candles_1d`، وهو الجدول الذي يقرأ منه تحليل جان.

## التعديل
`monitor/worker.py` الآن، مع كل فحص EGX ناجح:
1. يجلب تاريخ السهم من Yahoo.
2. يحفظ/يحدّث كل الشموع اليومية في `market_candles_1d`.
3. يخزن رمز مصر بصيغة Yahoo مثل `COMI.CA`.
4. بعدها يكمل تحليل R² + Slope المعتاد.
5. الحفظ يتم لكل سهم على حدة، لذلك لو توقف الفحص لا تضيع الأسهم التي تم حفظها بالفعل.

## بعد الـDeploy
اضغطي **تحديث بيانات السوق المصري** بعد أن يكون الـMonitor غير مشغول.

في Logs ستظهر أرقام مثل:
`gann_symbols=... gann_candles=...`

ثم من Shell شغلي:
```bash
python check_egx_gann_data.py
```

المفروض `EGX symbols` يكون أكبر من صفر.

بعدها افتحي:
`/gann?market=EGX`

## الملفات المهمة
- `monitor/worker.py` ← التعديل الأساسي المطلوب
- `check_egx_gann_data.py` ← فحص قاعدة البيانات
- باقي ملفات V3.2 مرفقة حتى تكون النسخة كاملة.
