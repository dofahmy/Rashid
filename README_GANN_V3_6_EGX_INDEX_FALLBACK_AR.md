# Gann V3.6 — EGX index fallback

المشكلة المثبتة:
- قاعدة البيانات تحتوي 210 سهمًا مصريًا و385,680 شمعة.
- `^CASE30` يعود بدون تاريخ من Yahoo chart endpoint داخل بيئة Railway.
- لذلك V3.5 لم تستطع تكوين Market Pivots.

الحل:
1. المحرك يحاول EGX30 الرسمي أولًا إذا كان موجودًا في `market_candles_1d`.
2. إذا لم يوجد، يبني تلقائيًا مؤشر سوق بديل من أعلى 30 سهمًا مصريًا حسب متوسط السيولة.
3. يتم Rebase لكل سهم إلى 100 ثم تكوين مؤشر متساوي الأوزان.
4. هذا المؤشر البديل يُستخدم فقط لاكتشاف تواريخ القمم والقيعان السوقية.
5. تأكيد الحدث ما زال يعتمد مستقلًا على:
   - Breadth لكل الأسهم
   - القياديات
   - البنوك
6. بعد تحديد تاريخ السوق، كل سهم يأخذ أدنى/أعلى سعر داخل ±3 جلسات كـ Gann anchor.

مهم:
المؤشر الصناعي ليس EGX30 الرسمي ولا يحاول تقليد أوزانه. هو fallback لاكتشاف turning points عندما يفشل مزود المؤشر.

بعد Deploy:
```bash
python check_egx_index_source.py
python check_egx_market_pivots.py
```
